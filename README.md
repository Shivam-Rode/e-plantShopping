# Paradise Nursery Shopping Application

## About the Project
Paradise Nursery is an online plant shopping application
that allows users to browse houseplants and manage their
shopping cart.

## Features
- Browse houseplants by category.
- View plant names, descriptions, and prices.
- Add plants to the shopping cart.
- Increase or decrease quantities.
- Remove plants from the cart.
- View the total shopping cart price.

## Technologies Used
- React
- JavaScript
- Redux Toolkit
- CSS

## How to Run
1. Clone the repository.
2. Run npm install.
3. Run npm run dev.
4. Open the local URL shown in the terminal.
